class Solution:
def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
max_d = 0
def dfs(node):
nonlocal max_d
if not node: return 0
l, r = dfs(node.left), dfs(node.right)
max_d = max(max_d, l + r)
return 1 + max(l, r)
dfs(root)
return max_d

Binary Tree Diameter from Absolute Zero

🌳 1. What is a Binary Tree?

A hierarchical structure where every node has at most two children: a left child and a right child. If a node does not have a child, that child pointer is None.

📏 2. What is Diameter? (Counting EDGES, not nodes!)

The diameter is the length of the longest path between any two nodes. Length is measured in number of edges (connections), NOT the number of nodes:

Path: 4 ── 2 ── 1 ── 3
Edges: (4→2) + (2→1) + (1→3) = 3 edges (has 4 nodes)

Notice that path 4 ── 2 ── 5 only has 2 edges, so it is shorter and does not win.

⚖️ 3. Crucial Distinction: Why TWO Formulas?

l + r = DIAMETER Combines left and right branches into an arch. This is checked for the high score max_d.
1 + max(l, r) = HEIGHT You can only return ONE branch upward to the parent. You choose the longer branch and add 1 for your own link!

🔥 4. Why do we need nonlocal max_d?

Because the longest diameter does NOT always pass through the root! If a deep subtree is very wide, the diameter lives entirely inside it. We update max_d at every single node visited so no subtree is overlooked!
