⚠️
The Single-Child Trap:

A node is ONLY a leaf if BOTH `left` and `right` are None! If a node has one child, the path must continue down through that child.

solution.py
Indent Level: 0
from collections import deque
class Solution:
def minDepth(self, root: Optional[TreeNode]) -> int:
if not root: return 0
q = deque([(root, 1)])
while q:
node, d = q.popleft()
if not node.left and not node.right:
return d # 🎯 First leaf wins!
if node.left: q.append((node.left, d + 1))
if node.right: q.append((node.right, d + 1))

The Water Ripple Analogy

Why BFS level-order finds the shortest distance first

Imagine dropping a pebble at the root (Node 3). Ripples expand outward in concentric circles.

Ring 1: Touches all nodes at distance 1 (Node 3). Is 3 a leaf? No, it has children.
Ring 2: Expands to distance 2 (Nodes 9 and 20). Is Node 9 a leaf? YES! It has no children!
Stop: Because water ripples expand uniformly, the FIRST leaf hit is mathematically guaranteed to be the closest leaf to the origin!

"We don't need to check Ring 3 (nodes 15 and 7) because distance 2 is already complete."

LeetCode 104 vs LeetCode 111

Why Maximum Depth uses DFS, but Minimum Depth prefers BFS

LeetCode 104: Max Depth

Must explore the entire tree.

return 1 + max(dfs(left), dfs(right))

You cannot exit early because a deeper leaf could hide anywhere at the very bottom.

LeetCode 111: Min Depth

Can exit immediately at the first leaf.

if not left and not right: return d

BFS level-order guarantees the first leaf popped is at the minimum depth. Pruning saves massive execution time!
