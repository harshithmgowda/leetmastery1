# 🚀 LeetMastery — DSA & LeetCode Studio

An interactive, high-performance Data Structures & Algorithms learning and interview preparation studio.

## 🌟 Key Features

- **⚡ Core Patterns (100+ LeetCode)**: Comprehensive breakdown of standard interview patterns (Sliding Window, Two Pointers, Dynamic Programming, Graphs, Heaps, Trees, and more).
- **⭐ Imp Questions (78 DSA in Python)**: Dedicated section covering 78 essential DSA problems with both **Best (Optimal)** and **Worst (Brute Force)** implementations.
- **🔬 Interactive Python Tutor Visualizer**: One-click step-by-step execution to trace memory pointers, recursion call stacks, variables, and arrays in Python Tutor.
- **🤖 Ask ChatGPT (ELI5) Assistant**: Approach-aware interview prompts breaking down algorithms line-by-line with beginner analogies.
- **📊 Detailed Dry Run Trace Tables**: Interactive step-by-step state tracking for every problem.
- **⚡ Dual Language Code Editor**: Instant switching between Python 3 and C++20 with syntax highlighting, copy, reset, and simulated test runner.
