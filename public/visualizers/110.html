class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def dfs(node):
            if not node:
                return 0
            l = dfs(node.left)
            if l == -1:
                return -1
            r = dfs(node.right)
            if r == -1 or abs(l - r) > 1:
                return -1
            return 1 + max(l, r)
        return dfs(root) != -1

THE BIG IDEA: The "-1" Signal

Instead of writing two separate helpers that cause a slow O(N²) recalculation, we combine status and height into ONE single integer:

Height ≥ 0 → Subtree is healthy!
Return -1 → Subtree is BROKEN!

-1 is NOT a negative height. It acts as an emergency signal that immediately short-circuits the rest of the recursion.

⏱️

Complexity: Bottom-Up vs Brute Force

Time Complexity: O(N)

Each node is visited once during the post-order DFS traversal.

Space Complexity: O(H)

Recursion stack depth equals tree height H (worst case O(N) for skewed tree, O(log N) for balanced).

Brute Force: Recalculating heights top-down costs O(N²) because nodes are repeatedly traversed.
🎯

Interview Mental Model

"I use bottom-up postorder DFS. For every node, I recursively obtain left and right subtree heights. If either returns -1, I propagate -1 up immediately. If |left - right| > 1, I return -1. Otherwise, I return 1 + max(left, right). Finally, I check if root != -1."

💡 Interview Pro-Tip: Highlighting early exit via -1 shows you understand both recursion call overhead and optimal time complexity.
