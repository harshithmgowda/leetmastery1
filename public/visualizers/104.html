class Solution:
def maxDepth(self, root: Optional[TreeNode]) -> int:
if not root:
return 0 # Base: empty subtree = 0
return 1 + max(
self.maxDepth(root.left),
self.maxDepth(root.right)
)

The Skyscraper Floor Analogy

How recursion calculates tree height

Imagine standing in the penthouse (Node 3). You cannot look directly to the ground through the floorboards.

1. You radio the West wing manager (Node 9): "How many floors are underneath you?"
2. You radio the East tower manager (Node 20): "How many floors are underneath you?"
3. If there are no floors underneath (empty ground / None), they report 0 floors.
4. West reports 1 floor. East reports 2 floors.
5. You pick the taller side (max(1, 2) = 2) and add +1 for your own penthouse floor = 3 floors tall!

"Children tell me how deep their branch is. I add 1 because I am also a node."

LeetCode 226 vs LeetCode 104

Understanding what the recursive return value actually represents

LeetCode 226: Invert Tree

Returns a TreeNode pointer.

root.left, root.right = right, left
return root 📦 (object)

The function modifies nodes and passes back memory addresses to stitch the altered tree together.

LeetCode 104: Max Depth

Returns an Integer number.

return 1 + max(L, R) 📦 (integer)

The function does NOT modify tree structures! It computes and returns scalar integers representing path length.
